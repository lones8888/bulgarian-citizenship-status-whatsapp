WhatsApp notification

Your existing WhatsApp Web session in this Chrome or Brave profile is used. A WhatsApp Web tab opens automatically if needed. If you haven't logged out, you don't need to scan the QR code again, and no extra program or command is needed.

This number's WhatsApp account must be open in WhatsApp Web in the same browser profile. Enter it in international format.

Enter each application's contacts and groups in its own section. An application without recipients is tracked only in the extension. PINs are never added to messages; incoming messages are not read.

“To myself” goes only to the sender number's own chat. “To recipients” sends a test message to all saved contacts and groups. Neither contains application details or PINs.

PINs are stored only locally in this browser profile and are not encrypted with the system keychain. They are sent only to the official status website. Chrome and Brave settings are independent of each other.

    Settings backup

    When moving the extension to another folder: “Back up settings” in the old one, “Restore from backup” in the new one. Everything saved is moved: numbers, PINs, WhatsApp settings, schedule, results, history and the delivery log (the same message is not sent twice). WhatsApp Web and notification permissions belong to the browser; allow them once in the new one. The backup file contains PINs: delete it after restoring.

    Checks need the Chrome or Brave where the extension is installed to be running and online. If the computer is off or asleep, a missed check runs when the browser runs again. You get a notification if human verification is needed.
